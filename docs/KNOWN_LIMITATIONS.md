# Known limitations and recovery

- **HARDWARE NOT VALIDATED:** zero physical sensors tested. BLE HRS discovery, notifications, no-data/disconnect/reconnect behavior and HTTPS ingestion are backend-tested using mocks. No device authentication, calibration or biomedical precision certification. No user API endpoint was validated; only NASA public requests were exercised online.
- Windows Application Control blocked SQLAlchemy's optional native `_result_cy` in a freshly installed environment. The documented upstream pure-Python source build of the same 2.1.8 version recovered startup; `py -3.14 scripts/install_windows.py --pure-python-sqlalchemy` reproduces it. [SQLAlchemy documentation](https://docs.sqlalchemy.org/en/21/intro.html#building-the-cython-extensions). No DLL was unblocked and no Windows security policy changed. A PowerShell helper was rejected by this machine's script policy during development and was discarded; the Python installer avoids that requirement. Other locally restricted native packages may still require administrator-approved alternatives.
- Installing Python requirements does not build external OHIF. The pinned revision/build instructions remain in README and `config/integration-versions.json`. If missing/incompatible, THEIA reports it; other workspaces continue. Never kill a process simply because its port is occupied. Use `python scripts/start_theia_services.py --ohif-only` and Recheck OHIF.
- If a source fails, polling pauses and records an error; correct its schema/credentials/path, then start authorized polling again. API transient GET failures retry once (two total attempts); credentials/query are omitted from request errors. Folder files must be stable over successive polls and end with a newline. Repeated receipts do not duplicate rows after restart.
- If an import reports synthetic rows in normal storage, use the isolated scenario instead. Do not change source labels to bypass the guard. Legacy mixed records are preserved, labeled and analyzed separately.
- Normal CSV/profile data stays in local SQLite. Backups precede additive upgrades; stop concurrent writers during migration. Local process locking is not distributed multi-user migration coordination. File/SQLite authorization relies on the Windows account; no multi-user authentication/role system is supplied.
- Automatic replay runs while its browser workspace is open; the explicit acquisition CLI is available for local unattended polling. It is not a spacecraft daemon or production remote synchronization service. The local mirror is synthetic only.
- Old measurements may lack receipt/device/batch evidence and remain UNKNOWN_UNVERIFIED. Old NN recordings without recording dates are omitted from date-scoped PDFs. Missing source information cannot be reconstructed retrospectively.
- A Windows asyncio connection-reset message can occur after browser shutdown; verify HTTP health/agent status before treating it as a persistent service failure. It was observed during development, not hidden; browser/app exceptions are checked separately.
- Existing tests retain four UTC deprecation warnings. No known undelivered critical data-integrity failure is accepted as a passing result; final evidence and exact validation scope are in FINAL_RELEASE_VALIDATION.md.

Scientific/clinical limitations are centralized in [SCIENTIFIC_LIMITATIONS.md](SCIENTIFIC_LIMITATIONS.md). The project is a local experimental demonstration, not a medical device or flight system.
